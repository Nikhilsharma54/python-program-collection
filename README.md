# Python Programs Collection

Three beginner Python programs written while learning the basics.

| File | What it does |
|------|--------------|
| `factorial.py` | Calculates the factorial of a number using a loop |
| `fibonacci.py` | Prints the first N numbers of the Fibonacci series |
| `struct_to_dict.py` | Converts a structure (a class object, or a list of key-value pairs) into a dictionary |

## How to run
Make sure Python 3 is installed, then run any file:

```
python factorial.py
python fibonacci.py
python struct_to_dict.py
```

## What I learned
Loops, functions, input validation, and how Python stores an object's fields in a dictionary.
